# ChronoCircle — 24시간 원형 대시보드 기반 스마트 일정 관리 프로그램 (223235 정우진)

## 빌드 및 실행 방법 (JDK 17+)

Windows에서 `run-chronocircle.bat`을 실행하면 앱을 컴파일한 뒤 GUI를 시작합니다. 컴파일된 클래스는 저장소의 `out` 폴더에 생성됩니다.

직접 실행하려면 저장소 루트에서 다음 명령을 사용하세요.

```bash
javac -encoding UTF-8 -d out ChronoCircleApp.java
java -cp out ChronoCircleApp
```

## 시각과 샘플 데이터

- 앱은 시작할 때 **오늘 날짜와 PC의 실제 시각**으로 열립니다. 날짜 옆 [오늘] 버튼을 누르면 언제든 실제 시각으로 돌아옵니다.
- 일정은 사용자 홈 폴더의 `.chronocircle_schedules_v2.ser`에 저장됩니다. 파일이 없으면 기준일(2026-10-15)·오늘·내일의 하루 일과와 이번 달 주요 일정을 샘플로 만듭니다.

### 샘플 일정을 현재 시각에 맞추기

시작할 때 오늘의 샘플 일과 5건(모닝 러닝, 특강, 실습, 캡스톤 회의, 알고리즘 스터디)을 현재 시각 기준으로 다시 배치합니다. 언제 켜도 바로 시연할 수 있습니다.

- 이미 끝난 일정 1건, **지금 진행 중인 일정 1건**, **약 2분 뒤 알림이 오는 일정 1건**, 이후 일정 2건으로 배치됩니다. 자정을 넘는 일정은 오늘 안으로 잘라 내거나 넣지 않습니다.
- 직접 만든 일정과 다른 날짜의 일정은 건드리지 않습니다. 제목과 장소가 샘플과 같은 일정만 샘플로 봅니다.
- 상단 **[설정]** 메뉴에서 켜고 끌 수 있고(기본값: 켬), **[지금 오늘 샘플 일정을 현재 시각에 맞추기]**로 바로 다시 배치할 수도 있습니다.

### 테스트 환경 재구축

저장된 일정을 지우고 샘플 데이터로 다시 만들려면 다음 명령을 실행합니다. 기존 파일은 같은 폴더에 `.bak`으로 백업됩니다.

```bash
java -cp out ChronoCircleApp --reset-data
```

### 기능 자동 점검

실제 데이터 파일을 건드리지 않고 임시 파일에서 핵심 기능(자연어 분석, 저장·수정·삭제, 임시 저장, 겹침 검사, 원형 각도 계산, 알림, 검색, 시각 이동)을 점검합니다. 샘플 재배치와 설정 저장도 확인합니다. 하나라도 실패하면 종료 코드 1을 돌려줍니다.

```bash
java -cp out ChronoCircleApp --verify-headless
```

## AI 자연어 일정 등록 (Gemini)

자연어 문장 분석에 Google Gemini API를 사용합니다. 키는 앱 안에서 등록하거나 환경 변수로 지정할 수 있습니다.

### 앱에서 키 등록 (가장 간단)

1. 상단 **[설정]** 메뉴의 **[Gemini API 키 설정…]**을 누르거나, [AI 프롬프트 등록] 창 왼쪽 아래의 **[AI 키 설정]**을 누릅니다.
2. 키가 없으면 창의 **[Google AI Studio에서 Gemini API 키 발급받기]** 링크를 누릅니다. 기본 브라우저에서 https://aistudio.google.com/apikey 가 열립니다 (Google 계정 로그인 필요).
3. 발급받은 키를 붙여 넣고 **[연결 테스트]**로 키와 모델이 쓸 수 있는지 확인합니다.
4. **[저장]**을 누르면 다음 AI 분석부터 바로 적용됩니다. 앱을 다시 시작할 필요가 없습니다.

- 키는 이 PC의 사용자 홈 폴더 `.chronocircle_config.properties`에 저장됩니다. 저장소에는 들어가지 않습니다.
- 같은 창에서 모델을 바꾸거나, [저장된 키 삭제]로 지울 수 있습니다.
- 여러 곳에 키가 있으면 `-Dgemini.api.key` 실행 옵션, 앱 설정, 환경 변수 `GEMINI_API_KEY` 순서로 앞의 것이 쓰입니다. 설정 창에 지금 어느 키가 쓰이는지 표시됩니다.

### 환경 변수로 키 등록

Windows 사용자 환경 변수에 한 번 등록해 둘 수도 있습니다. 등록한 뒤로는 jar 더블클릭, `java -jar`, `run-chronocircle.bat` 어느 방법으로 실행해도 키를 다시 입력할 필요가 없습니다.

- **설정 화면:** 시작 메뉴에서 "시스템 환경 변수 편집" → [환경 변수] → 사용자 변수 [새로 만들기] → 이름 `GEMINI_API_KEY`, 값에 발급받은 키 입력
- **명령어:**

  ```bat
  setx GEMINI_API_KEY "발급받은_키"
  ```

등록한 뒤 **새로 연 창부터** 적용됩니다. 이미 열려 있는 터미널이나 실행 중인 앱은 다시 실행해야 합니다.

### 이번 실행에만 쓰기

키를 저장하지 않으려면 실행하는 창에서 직접 지정합니다. 키를 지정한 같은 창에서 앱을 실행해야 적용됩니다.

```bash
# Windows (cmd)
set GEMINI_API_KEY=발급받은_키
# Windows (PowerShell)
$env:GEMINI_API_KEY = "발급받은_키"
# macOS / Linux
export GEMINI_API_KEY=발급받은_키
```

환경 변수 대신 `java -Dgemini.api.key=발급받은_키 -cp out ChronoCircleApp`처럼 시스템 속성으로 지정할 수도 있습니다.

### 동작 확인

일정 등록 창에서 문장을 입력하고 "AI 자동 분석"을 누르면, 아래 상태 문구로 어떤 방식으로 분석했는지 알 수 있습니다.

| 상태 문구 | 의미 |
|---|---|
| `Gemini(gemini-3.8-flash) 분석 완료…` | Gemini로 분석함 |
| `Gemini 분석 실패(HTTP 400)…` | 키가 잘못됨 (내장 파서로 대신 분석) |
| `Gemini 분석 실패(HTTP 404)…` | 지정한 모델을 이 키로 쓸 수 없음 |
| `내장 파서 분석 완료…` | 키가 앱에 전달되지 않음 |

### 참고

- 기본 모델은 `gemini-3.8-flash`이며, 키 설정 창이나 `GEMINI_MODEL` 환경 변수로 바꿀 수 있습니다 (설정 창 값이 우선).
- 키가 없거나 네트워크 오류가 나면 내장 한국어 정규식 파서로 대신 분석하므로, 키 없이도 앱은 정상 동작합니다.
- 키는 PC마다 따로 등록해야 합니다. 저장소나 소스 코드에 키를 넣지 마세요.

## 일정 알림

알림 시각이 되면 화면 상단에 알림 배너가 펼쳐지고, 운영체제가 시스템 트레이를 지원하면 트레이(Windows 작업 표시줄 오른쪽 아래)에도 알림이 표시됩니다.

- 트레이 알림이나 트레이 아이콘을 더블 클릭하면 앱 창이 앞으로 나오고 해당 일정의 상세 창이 열립니다.
- 트레이 아이콘을 오른쪽 클릭하면 [ChronoCircle 열기], [종료] 메뉴를 쓸 수 있습니다.
- Windows 알림이 꺼져 있거나 집중 모드(방해 금지)가 켜져 있으면 트레이 알림이 보이지 않을 수 있습니다. 이때도 상단 배너 알림은 표시됩니다.

### 알림 테스트

상단 **[알림 테스트]** 버튼을 누르면 앞으로 울릴 가장 가까운 알림의 시각 직전(3초 전)으로 시계를 잠시 옮깁니다. 그러면 실제와 같은 경로로 상단 배너와 트레이 알림이 뜹니다.

- 테스트 중에는 시계 옆에 `(알림 테스트 중)`이 표시되고, 알림이 뜨고 6초 뒤(늦어도 15초 뒤) 실제 시각으로 돌아옵니다.
- 테스트로 보낸 알림은 기록에서 지우고 일정의 알림 시각도 그대로 되돌리므로, 실제 알림 시각이 되면 알림이 다시 정상적으로 옵니다.
- 앞으로 울릴 알림이 없으면 오늘 샘플 일정을 현재 시각에 맞춰 다시 배치할지 묻습니다.
